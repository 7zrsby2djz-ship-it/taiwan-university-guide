# 偉銓選校板：第二輪實際操作與優化

日期：2026-10-31。起點為 `5295d0a`；這一輪只調整個人選校板及其規則、測試、文件。

## 操作中發現的缺口

1. 已能篩選全部 39 校，但還不能固定比較少數候選學校。每次改搜尋，想看的對象便分散在不同位置。
2. 進度只記「已報名」，不能記季別及梯次。實測朝陽時只能看到最早放榜參考 12/18，無法指定第二梯的 2027/1/15。

## 已完成

| 功能 | 行為 |
| --- | --- |
| 三校比較 | 卡片按「加入比較」固定最多三校；獨立於搜尋及篩選，可移除、清空、重新整理恢復。 |
| 逐項比對 | 學雜費、申請費、來源年度、距離、官方截止、春季情況、秋季放榜、語言、確定優惠、審查獎學金、續領及商管榜單，分列顯示。沒有推算未確認的費用。 |
| 手機操作 | 底部捷徑可返回比較；比較區可橫向捲動，項目標題固定，整頁不橫向溢出。 |
| 分享比較 | 選校 ID 可隨篩選網址分享；自己的申請梯次、狀態、備註及草稿不會寫進網址。 |
| 指定申請梯次 | 我的申請可選 2027 春／秋與第幾梯；每校目前追蹤一個梯次。舊進度不會自動猜成某一梯。 |
| 對應下一步 | 所選梯次分別顯示未開放、開放待確認、截止、等待放榜、等待寄發入學許可、放榜日已到等提示。原始概略月份、往年與未知日期都不做精確倒數。 |
| 異動處理 | 當所選梯次的日期、狀態、年份或排序位置不再相符，提示重新確認；不把舊申請默默套到另一梯。 |
| 儲存 | 梯次與原狀態、備註分開保存；同校連續修改依序寫入。原有雲端介面保留新欄位，唯讀使用者的選單停用。 |

## 驗證

- `node --check dist/wq-board.js`、`node --check dist/wq-core.js`、`npm test`。
- 三校上限、同校不重複、改搜尋／篩選後保留、移除／清空、網址與本機保存、空白分享選校覆蓋舊本機選擇。
- 朝陽第二梯精確對到 2027/1/15；放榜之後轉為 1/22 寄發提示，寄發當天仍顯示該項目，日期已過則提示查詢結果。
- 未確認開放、已截止、官方概略月份、歷年參考、資料異動、儲存失敗與舊進度相容。
- 備註草稿在選梯次時保留；複製進度包含梯次，分享篩選不含個人進度。
- 模擬既有雲端介面，確認同時修改梯次和備註不互相覆蓋、本機進度匯入保留梯次、唯讀選單停用。這是模擬測試，沒有改動正式雲端資料。
- Chrome 實際操作繁中／緬文，390px 三校比較及 320px 梯次選單；檢查頁面無水平溢出，並以鍵盤確認比較區可水平捲動。不是實體 iPhone／Safari 測試。

主站 `app.js`、`core.js`、`index.html`、`styles.css` 與 139 校／39 校招生資料都未變動。招生來源仍是原本的 2026-10-15 查核快照。沒有新增學校、改金額或日期，也沒有替任何人送出學校報名。

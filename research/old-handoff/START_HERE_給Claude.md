## 執行
這是原生 HTML/CSS/JavaScript 靜態網站，沒有後端、登入或資料庫，不需要 build。
在專案根目錄執行：

```sh
python3 -m http.server 8000 --directory dist
```

瀏覽 http://localhost:8000/?lang=zh 。請不要直接用 file:// 開啟，JSON 透過 fetch 讀取。

測試需要 Node.js 22+ 和 npm：

```sh
npm install
npm test
```

本交接包將測試內的原環境絕對路徑改成標準 linkedom 套件匯入，並加上 package.json；dist 完全保持已發布版本。測試是 DOM 模擬，不等於實際手機／瀏覽器視覺驗證。

## 資料規則（重要）
- 目標春季是 2027／115-2；秋季是 2027／116-1。
- 最新可取得官方資料優先；沒有最新年度時使用最近官方年度並清楚標示年份。不要把去年日期加一年當正式日期。
- official 才有正式 date；historical 保留原年度日期及參考文字。sort 僅是排序／月份規劃鍵，不是正式申請日期。
- 衝突保留來源與說明，不自行選一邊；缺資料不能填 0。
- 申請費 0 必須有官方明文免收。沒有列出費用，不代表免費。先前「僅限114簡章」規則已取消，採最近可確認官方年度。
- 一般外國學位生不得混入僑生、交換、華語、國際專修部或產學專班；學士與研究所範圍要區分。
- 獎學金保留適用年度、學位、金額、期間及審核／續領條件，不能把競爭型獎學金當保證取得。
- 榜單只存官方公告／附件連結、年度與學期。不要 OCR、解析姓名、推測國籍或統計人數。
- 錄取公告不是正式入學許可；人數不是錄取率。
- 沿用現有可靠資料；只研究缺失、過期或矛盾項目。
- 保留繁中／緬文切換、收藏、CSV、分享、地圖、排序與官方入口。

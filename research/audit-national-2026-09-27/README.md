# 2026-09-27：17校官方資料查核與28校快速篩選

本批學校：彰師、暨南、聯合、臺大、清華、陽明交大、政大、成大、中央、中山、中正、臺師大、臺北大學、海大、臺科、雲科、北科。沿用原139校名單，122筆其他學校紀錄不變，前批11校研究資料不變。

- `facts.json`／`facts.py`：本批可追溯資料與逐校缺口；11校申請費有明文，其中4校明確免收；另6校未能核得全校金額。
- `sources.json`：讀取過的官方文件網址。學校官方公告指定的Google Drive或表單仍保留指定網址。
- `merge.py`：從version8備份合併，舊時程保留為archived；不把歷年日期加一年當正式日期。
- `report.py`：產生公開逐校核對報告。
- `validate.mjs`：資料範圍、來源年度、費用缺值、時程衝突、春秋與學位範圍檢查。
- `interface-qa.mjs`：快速篩選URL、28校／臺中11校、語言、學期、城市、收藏、空結果恢復等DOM測試。

錄取榜單只保存官方公告／附件連結；沒有解析榜單、保存學生姓名或計算錄取率。中山提供個人結果查詢公告，未宣稱有公開名冊。所有17校均為部分完整，逐校缺口在詳細頁與公開報告列出。

## 驗證結果

通過原有 `qa.mjs` 全套DOM功能驗證，涵蓋139校名單、時程來源、日期排序、中緬切換、春秋切換、收藏、匯出、地圖、字級及行動版篩選操作；本批新增資料與快速篩選測試亦通過。

這是DOM模擬與響應式CSS檢查，沒有宣称已完成真實瀏覽器畫面檢查。原有字體與版型沿用；新按鈕可換行，600px以下滿寬，最小高度46px。

## 快速篩選定義

`reviewState`為`audited`或`partially_audited`即納入，共28校。包括前批亞洲與僑光的部分查核紀錄，不將它們的未知費用或獎學金誤寫為已確認。其他早期研究學校不自動納入。本按鈕保留其他篩選條件，狀態以`audited=1`保存於分享網址。
